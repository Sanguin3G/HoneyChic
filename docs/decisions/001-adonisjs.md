# 001 — AdonisJS 7

**Decision:** Use AdonisJS 7 and TypeScript, based on the official Vue starter.

**Why:** A cohesive full-stack framework keeps routing, validation, sessions, ORM, and tooling understandable while supporting the rewrite's learning goals.

**Alternatives rejected:** Mechanically translating Laravel preserves old coupling. A collection of independent backend libraries adds integration work before commerce exists.
