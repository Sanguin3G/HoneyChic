# HoneyChic design foundations

Semantic tokens, elevation, control states, and reduced motion live here. Current primitives are `HcButton`, `HcPanel`, `HcInput`, `HcTextarea`, `HcNotice` and `HcDialog`. Add other primitives when actual screens need them.

Navy and warm orange identify the platform. Merchant names are configured separately. Controls have visible hover, pressed, selected, disabled, and keyboard focus states. Mobile targets remain at least 44px high.

Read [UI rules](../../../docs/UI.md) before changing the visual language.

Forms and admin/account layout styles use semantic tokens. Keep feature forms outside the design folder.
